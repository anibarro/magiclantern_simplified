Live Composite LCM20 - Canon EOS M firmware 2.0.2

INSTALL
Copy ML/modules/livecomp.mo to the same location on your ML card, replacing
only that module. Enable livecomp.mo in the Modules tab and reboot.
Keep your existing autoexec.bin and its matching EOSM_202.sym together.
No replacement core, symbol file or other module is included or required.
Uses standard ML core RAW, FPS and display-filter APIs. Import compatibility
was checked against this repository's unmodified EOSM.202 core; an unrelated
older ML build may lack APIs and refuse to load the module.

USE
1. Movie mode, manual exposure/ISO and fixed white balance; normal unzoomed view.
2. Set ML FPS override to 3 fps, Low light, and the slowest available shutter.
   Enable Global Draw. Disable other RAW recording/capture tools.
3. Shoot > Live Composite: ON. Open its submenu for settings:
   Task: Live composite (default), Full-res check (old diagnostic, paused)
   Full-res readout (single-capture test) or Full-res composite (LCM17, below).
   Capture limit: 30 / 60 / 120 frames (default 120).
   LCD refresh: every 1 / 2 / 4 seconds (default 1).
4. Close the menu. Nothing starts until you press and release SET in normal Live View.
5. Press SET again to stop and save, or wait for the frame limit.
   LCD shows the growing composite. Every admitted RAW input is merged.
   After saving completes, the module returns to Armed; press SET to start again.
6. LVCPnnnn.DNG, LOG and CSV are saved at the card root. Each capture uses a new filename.
   Off returns Q/SET to its ordinary function.

Normal photos do not trigger this version. Short SET acts on the physical release. Long SET also works; its synthetic and physical releases do not trigger a second action.
The confirmed continuous path
requires Movie Live View, so Q/SET is the explicit start-button fallback.
The first streaming RAW frame is the base image; no mechanical photo is taken.
The input resolution is normal Live View (measured 1808x727, active 1736x697),
not full sensor resolution. DNG output retains LCM5's fixed daylight metadata;
exact white balance, longer captures and full resolution remain future work.

FULL-RES COMPOSITE (LCM17) - 5208x3478 light painting, first version
Same setup as the readout test below (Movie M, FPS override OFF, Global Draw
OFF, no other RAW tools, fixed ISO/WB, x1 view). Submenu:
   Task: Full-res composite
   Full-res FPS: 0.25 fps (4 s) - each frame is one ~4 s sub-exposure
   Full-res exposure: 100% of frame (gapless as possible)
   Capture limit: 30 / 60 / 120 frames
   Focus pixels: Fix (default) removes the EOS M dot grid from the DNG
   HW merge test: On (default) tests Canon's hardware max once, on frame 3
The DNG white balance follows Canon's WB setting (Kelvin or preset).
Close the menu, press SET once. The camera zooms to x5. After ~8 s the LCD
shows the growing composite (low-res monitor view, refreshed every frame;
Canon's garbage view may flash briefly at each frame). Press SET to stop, or
wait for the limit. The camera returns to x1 and saves LVFRnnnn.DNG (full-res
composite), .LOG and .CSV (one line per merged frame).
Every completed frame is merged. If a merge does not finish before the next
frame starts arriving, the session stops and saves what it has ("stopped
early"): choose a slower FPS. 0.33 fps is borderline, 0.5 fps and faster
will stop. Brightness: each frame is a full 4 s exposure - use ISO 100 and
stop down (f/8-f/16) as for an Olympus Live Composite base exposure.

FULL-RES READOUT TEST (LCM15) - first full-sensor capture attempt
What it does: switches the sensor into a full-sensor x5 readout (the EOS M
"Full Res" mode from Bilal's crop_rec, ~5200x3480 at 3 fps or slower),
captures 1/4/8 RAW frames into the module's own buffer, max-merges them,
returns to normal view and saves LVFRnnnn.DNG + LVFRnnnn.LOG at card root.
The LCD will look wrong (cropped/frozen/stretched) while the test runs: Canon's
preview is not adapted. That is expected. Only the DNG/LOG matter.
Setup:
 a. Movie mode, M exposure, fixed ISO (100-400) and WB, normal view (x1).
 b. ML FPS override: OFF. Global Draw: OFF. No crop_rec, mlv_lite, raw video,
    silent pictures or other RAW tools loaded/active.
 c. Point at a static, reasonably lit scene (lamp, window). The exposure is
    set by the module as a fraction of the frame, not by Canon's shutter.
 d. Shoot > Live Composite: ON. Submenu:
      Task: Full-res readout
      Full-res FPS: any (3 fps, 1 fps, 0.5 and 0.33 fps were tested OK)
      Full-res exposure: 100% (first run). Lower % if the DNG is overexposed.
      Full-res frames: 1 frame (first run), then 4 frames
 e. Close the menu and press/release SET once. Do not touch any control.
    The camera zooms to x5, captures, then returns to normal view by itself
    (about 5-20 s). A message reports the result. SET cancels.
 f. Copy LVFRnnnn.LOG and LVFRnnnn.DNG from the card root. If the camera
    freezes, remove the battery, then still collect the LOG (it is written at
    every stage).
If the message says "ownership uncertain", reboot before anything else.

FULL-RES CHECK (NOT A FULL-RES CAPTURE MODE)
Set Canon image quality to RAW only (without JPEG) before restarting the camera.
Select Task: Full-res check, then close the menu and press/release SET. Keep the camera
in normal Movie Live View with other RAW tools off. The check reserves up to
four large buffers and tests Canon's native maximum engine on synthetic
5280x3508 RAW data while Live View runs. It never changes the sensor readout.
LCM14 tests output DMA channel 3 with its own resource lock. LCM12 showed
channel 6 being reconfigured during the test, so that route is no longer used.
The check now requires reboot if a DMA destination changes unexpectedly. It first samples Canon resource availability and
records picture quality. It saves LCFRnnnn.LOG, not a photograph. Hold SET to cancel between operations.
Allow the check to finish and retain the log, including when it reports an
unavailable engine or insufficient memory. No separate crop_rec module is needed.
Select Task: Live composite to return to normal capture. The task selection
resets to Live composite at boot. An uncertain engine/hook/buffer state requires
reboot; successful completion or clean refusal permits another session.

VALIDATION
LCM15/16 Full-res readout passed on camera at 3, 1, 0.5 and 0.33 fps.
LCM17 Full-res composite has NOT been run on a camera yet (host simulation only).
LCM8 captured and merged 76 frames on camera with LCD preview and a saved DNG.
LCM14 adds destination ownership checks and tests a different output channel; its native engine has NOT yet
been validated alongside Live View. Host tests cover error handling and full
5280x3528 DNG output. Passing those tests does not prove hardware operation.
If an error appears, retain the LOG/CSV/DNG. Reboot is required only when
Status explicitly says capture ownership is uncertain. Safe failures allow retry.
