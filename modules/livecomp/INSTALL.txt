Live Composite LCM53 - Canon EOS M firmware 2.0.2

Olympus-style Live Composite for the EOS M at full sensor resolution
(5208x3478): the camera keeps exposing frames of the chosen shutter speed,
and every frame is merged into a composite that keeps the brightest value
of each pixel (light trails, light painting, star trails over a fixed
foreground). The result is an uncompressed RAW DNG in DCIM/LIVE on the card.

INSTALL
Copy ML/modules/livecomp.mo to the same location on your ML card, replacing
only that module. Enable livecomp.mo in the Modules tab and reboot.
Keep your existing autoexec.bin and its matching EOSM_202.sym together.

CAMERA SETUP
 - Movie mode, M exposure, fixed ISO (not Auto; 100 recommended), fixed WB,
   normal view (x1). Camera on a tripod.
 - Aperture and ISO: the camera's own settings; the shutter: this menu.
 - ML FPS override OFF; no other RAW tools (crop_rec, mlv_lite, raw video,
   silent pictures). Global Draw may stay ON: it is turned off while a
   session runs and restored afterwards.

MENU (Shoot > Live Composite)
   Live Composite   ON arms the module. Nothing starts until you press SET.
   Shutter          2.5 s ... 60 s (default 2.5 s): the exposure of every
                    frame; frames follow each other with no gap. The right
                    side shows the camera's ISO and aperture.
                    The LCD shows the whole composite after every frame.
                    2.5-5 s and 10 s are camera-tested; the others are
                    marked "not yet tested". Shorter shutters are not
                    offered: merging a frame takes ~1.5-1.9 s, so at 2 s the
                    camera had no time left for its buttons and display.
   Preview only     OFF (default) / ON. ON: SET takes ONE frame with the
                    current shutter, ISO and aperture and shows it with its
                    settings and the share of clipped highlights. Nothing is
                    saved. SET returns to Live View; adjust and repeat, then
                    set Preview only OFF for the real composite.
   Frame limit      No limit (default) / 30 / 60 / 120 / 240 frames.
   Debug            OFF (default): only the DNG is written, no log files.
                    ON: diagnostic LVFRnnnn.LOG and .CSV next to each DNG
                    (and DCIM/LIVE/LVPREVW.LOG for Preview only). Turn it on
                    when reporting a problem.
   Status           Off / Armed / Starting / Running / Reboot, with the
                    setup reminder or the last result. In photo mode it shows
                    "Needs Movie mode" and the module does nothing (SET keeps
                    its normal Canon function).

RUN
 1. (Optional) Preview only ON, close the menu, press SET: after one shutter
    time plus about 1.5 s the frame appears with
       PREVIEW  2.5 s  ISO 100  f/8.0  clipped 0.3%
    Press SET to return. Change ISO/aperture (camera) or shutter (menu) and
    repeat until the exposure is right. Then Preview only OFF.
 2. Close the menu and press/release SET. The camera switches to the
    full-sensor mode at 3 fps (about 1 s), then the first frame at your
    shutter starts: it is ready after one shutter time ("First frame in
    about n s") and is the base of the composite. Canon's zoom box and
    arrows are hidden while the session runs.
 3. "COMPOSITE n  SET=stop": the LCD shows the growing composite. Press SET
    to stop: the exposure in progress is completed and merged. Or wait for
    the frame limit.
 4. The camera returns to normal view and saves DCIM/LIVE/LVFRnnnn.DNG
    (composite, camera WB as DNG white balance, EOS M focus pixels removed;
    the folder is created if needed; Canon's playback does not show it).
    With Debug ON also .LOG and .CSV. Press SET again for another session;
    no reboot needed.
 While a session runs only SET acts; the other buttons are held so the
 camera does not react to them in the full-sensor mode.

BATTERY
When the battery indicator drops to its last (red) level during a session,
the session stops like SET and the composite is saved while there is still
power for the card write ("Battery low: composite saved").

GOOD TO KNOW
 - A frame that arrives while the previous merge is still running is skipped
   (a short gap) and counted; if that keeps happening the session stops and
   saves ("Merge too slow"): use a longer shutter.
 - Around the 5th frame Canon cuts one readout short. That frame is still
   merged (the missing rows hold the previous frame) and logged.
 - The DNG holds the whole 5280-pixel-wide raster with the active area
   marked for the raw converter.

IF SOMETHING GOES WRONG
Turn Debug ON and repeat: the LOG/CSV in DCIM/LIVE are written at every
stage, so they survive an interrupted session. A
refusal message (wrong mode, Auto ISO, FPS override on, another RAW tool)
changes nothing: fix it and press SET again. Only if Status says "Reboot"
(RAW DMA ownership uncertain) must the camera be restarted. If the camera
ever freezes, remove the battery, then collect the LOG (Debug ON).
